# OCR recognition model

`cyrillic_PP-OCRv5_rec_mobile.onnx` and `ppocrv5_cyrillic_dict.txt` are from the
[RapidOCR PP-OCRv5 model catalog](https://github.com/RapidAI/RapidOCR/blob/main/python/rapidocr/default_models.yaml).
The Cyrillic dictionary contains both Cyrillic and Latin characters. The model's
SHA-256 is `90f761b4bfcce0c8c561c0cb5c887b0971d3ec01c32164bdf7374a35b0982711`.
